# DIASS Module 1 Summative Review

A self-contained, responsive Grade 12 summative review on the Discipline of Counseling. It generates a 25-item assessment containing 30% LOTS and 70% HOTS, provides post-submission feedback, supports retakes, restores browser progress, and creates a printable certificate.

## Included files

- `index.html` — the complete interactive website
- `.nojekyll` — ensures GitHub Pages serves it as a plain static website
- `README.md` — deployment and troubleshooting instructions

No installation, database, external library, account, or build command is required.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Extract this package and upload the three files inside the folder to the repository root. Keep `index.html` unchanged.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub to display the published address.

The website address normally follows this format:

```text
https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/
```

## Browser and device support

The responsive layout is designed for current versions of Safari, Chrome, Edge, and Firefox on iPhone, iPad, Android, Windows, macOS, tablets, laptops, and desktop computers. It supports touch, mouse, keyboard navigation, and browser zoom.

## Saved progress and privacy

The current question set, learner details, selected answers, attempt, and submitted result are stored only in the current browser. They are not transmitted to GitHub or to the teacher.

- Use the same browser and device to resume progress.
- Private browsing, blocked storage, clearing browser data, or changing devices may prevent restoration.
- The certificate records the check-in and completion times.
- The certificate can be printed or saved as a PDF through the device's print screen.

## Troubleshooting

- **404 page:** verify that `index.html` is in the repository root and Pages uses `main` and `/ (root)`.
- **Changes are not visible:** wait for deployment, then refresh without cache.
- **Progress is not retained:** leave private browsing and allow website storage.
- **Print does not directly download:** select **Save as PDF**, **Microsoft Print to PDF**, or the iOS/iPadOS Share option.
